## Overview

Every signal, component, port, group, collection, cycle and the mesh itself carries a **metadata store**: `meta.Meta`, a map from string keys to string or numeric values. Metadata is inspired by Kubernetes labels and is what you route on, filter by and debug with — without touching the payload.

One store, one key space, two value types:

- **string** — `"priority": "high"`, `"source": "sensor1"`
- **float64** — `"weight": 0.85`, `"latency_ms": 42.0`

The type is chosen per entry, not per store. Writes infer it from the value; reads name it at the call site. Both live in the [meta package](https://pkg.go.dev/github.com/hovsep/fmesh/meta).

## Core API

```go
m := meta.New()

// Write (upsert). T is inferred from the value.
m.Set("env", "prod")
m.Set("weight", 0.85)
m.SetMany(map[string]string{"region": "us-west", "tier": "backend"})
m.SetMany(map[string]float64{"latency_ms": 42, "retries": 0})

// Read. Name the type you expect.
env, err := m.Value[string]("env")       // error if absent or not a string
w, err := m.Value[float64]("weight")     // error if absent or not a float64

// Or infer it from a default / comparison value.
region := m.ValueOrDefault("region", "unknown")
weight := m.ValueOrDefault("weight", 0.0)
if m.ValueIs("env", "prod") { /* ... */ }
if m.ValueIs("retries", 0.0) { /* ... */ }

// Presence
m.Has("env")                  // true
m.Has("env", "weight")        // all present
m.HasAny("dev", "staging")    // at least one present

// Shape
m.Keys()      // sorted
m.Len()
m.IsEmpty()
m.All()       // map[string]any copy

// Remove
m.Remove("retries", "tier")
m.Clear()

// New stores
copy := m.Clone()
strings := m.Filter(func(key string, value any) bool { _, ok := value.(string); return ok })
```

### Two things the compiler enforces

**Only `string` and `float64`.** An untyped integer literal does not compile:

```go
m.Set("count", 3)     // compile error: int does not satisfy meta.Value
m.Set("count", 3.0)   // ok
m.ValueOrDefault("count", 0)    // compile error
m.ValueOrDefault("count", 0.0)  // ok
```

This is deliberate. It is the one spot where a silent bug could hide, so it is a loud error instead.

**A key holds one type at a time.** Writing `Set("k", 1.0)` over `Set("k", "one")` replaces the entry. Reading with the wrong type is an error from `Value`, and reads as absent from `ValueOrDefault`, `ValueIs`:

```go
m.Set("port", "8080")
_, err := m.Value[float64]("port")   // meta "port" holds string, not float64
m.ValueOrDefault("port", 0.0)        // 0.0
m.ValueIs("port", 8080.0)            // false
```

## Two API styles: copy-on-write vs mutating

| Entity | Style | Add one | Add many | Remove | Replace all |
|--------|-------|---------|----------|--------|-------------|
| `signal.Signal` | Copy-on-write (`With*`) | `WithMeta(k, v)` | `WithMetaMany(map)` | `WithoutMeta(keys...)` | `WithoutMeta(s.Meta().Keys()...).WithMetaMany(map)` |
| `signal.Group` (its own store) | Copy-on-write | `WithMeta(k, v)` | — | — | — |
| `component`, `port`, `fmesh`, `cycle`, collections | Mutating — go through the store | `Meta().Set(k, v)` | `Meta().SetMany(map)` | `Meta().Remove(keys...)` | `Meta().Clear().SetMany(map)` |

Signals and signal groups are **immutable** — `With*` methods return a new value, and they are the only way to get a modified signal. On both, `Meta()` returns a **copy**: mutating it changes nothing, so go through `WithMeta` and assign the result. Components, ports and meshes are **mutable**, carry no metadata methods of their own, and `Meta()` hands you the live store. Chaining still works, on the store:

```go
c.Meta().Set("layer", "business-logic").Set("owner", "team-a").Set("weight", 0.5)
```

The split means `With*` has exactly one meaning across the whole API — it returns something new.

## Signals

### Adding metadata

```go
sig := signal.New("temperature: 25°C").WithMetaMany(map[string]string{
    "source":   "sensor1",
    "type":     "temperature",
    "priority": "normal",
})

// Chain — and assign the result!
sig = sig.WithMeta("processed", "true").
    WithMeta("confidence", 0.97)
```

### Querying

```go
if sig.Meta().Has("priority") { /* ... */ }
if sig.Meta().ValueIs("priority", "high") { /* ... */ }

priority := sig.Meta().ValueOrDefault("priority", "normal")
confidence := sig.Meta().ValueOrDefault("confidence", 0.0)
```

### Filtering with predicates

```go
highPriority := port.Signals().Filter(signal.MetaEquals("priority", "high"))
confident := port.Signals().Filter(signal.MetaEquals("confidence", 1.0))

fromSensor1 := port.Signals().Filter(signal.And(
    signal.HasMeta("source"),
    signal.MetaContains("source", "sensor"),
))

urgent := port.Signals().Filter(signal.HasAnyMeta("urgent", "critical", "emergency"))
complete := port.Signals().Filter(signal.HasMeta("trace-id", "span-id"))
```

Available helpers: `Not`, `And`, `Or`, `HasMeta`, `HasAnyMeta`, `MetaEquals`, `MetaContains`.

Metadata travels with the signal through pipes, so it is a reliable way to track data across the mesh.

## Components

```go
c, _ := component.New("processor",
    component.WithMeta("layer", "business-logic"),
    component.WithMeta("weight", 0.5),
    component.WithInputs("in"),
    component.WithOutputs("out"),
    component.WithActivationFunc(myFunc),
)

// After creation — the live store
c.Meta().Set("version", "2.0").Set("owner", "team-a")
c.Meta().Clear().SetMany(map[string]string{"layer": "business-logic", "criticality": "high"})

// Query and filter
if c.Meta().ValueIs("criticality", "high") { /* ... */ }

critical := fm.Components().Filter(func(c *component.Component) bool {
    return c.Meta().ValueIs("criticality", "high")
})
monitored := fm.Components().Filter(func(c *component.Component) bool {
    return c.Meta().Has("owner", "environment")
})
```

## Ports

```go
dataPort, _ := port.NewInput("data",
    port.WithMeta("type", "primary"),
    port.WithMeta("required", "true"),
)

c.InputByName("config").Meta().
    Set("type", "configuration").
    Set("optional", "true")

required := c.Inputs().Filter(func(p *port.Port) bool {
    return p.Meta().ValueIs("required", "true")
})
```

## Groups and collections

Every group and collection carries its **own** store, separate from its contents. `signal.Group` additionally supports batch operations on its contents (copy-on-write — each call returns a new group):

```go
// On every signal in the group
tagged := port.Signals().WithMetaOnEach("batch", "2024-01-01")
tagged = tagged.WithoutMetaOnEach("draft")

// On the group itself
tagged = tagged.WithMeta("source", "pipeline")
```

The mutating collections (`port.Collection`, `component.Collection`, `cycle.Group`) carry no batch methods; iterate with `ForEach` and go through each element's own store.

## Common use cases

### Priority-based routing

```go
_, _ = component.New("router",
    component.WithInputs("in"),
    component.WithOutputs("high-priority", "low-priority", "normal"),
    component.WithActivationFunc(func(ctx context.Context, c *component.Component) error {
        return c.InputByName("in").Signals().ForEach(func(sig *signal.Signal) error {
            switch sig.Meta().ValueOrDefault("priority", "normal") {
            case "high":
                return c.OutputByName("high-priority").PutSignals(sig)
            case "low":
                return c.OutputByName("low-priority").PutSignals(sig)
            default:
                return c.OutputByName("normal").PutSignals(sig)
            }
        })
    }),
)
```

### Measurements next to their tags

```go
sig := signal.New("air").
    WithMeta("category", "gas").
    WithMeta("temperature", 26.4).
    WithMeta("humidity", 0.55)

if sig.Meta().ValueIs("category", "gas") {
    t := sig.Meta().ValueOrDefault("temperature", 0.0)
}
```

### Source tracking and observability

```go
sig := signal.New(data).WithMetaMany(map[string]string{
    "source":     "api-gateway",
    "request-id": "abc-123",
    "trace-id":   generateTraceID(),
})
```

## Best practices

- **Consistent naming.** `app.name`, `app.version`, `app.environment`.
- **Payload for data, metadata for context.** Keep the store small; it is cloned with every copy-on-write operation.
- **One type per key, mesh-wide.** The store does not know that `"temperature"` is always a number — your components agree on that. Keep the agreement in one place (a `const` per key, or a small `pack`/`unpack` pair) so a string never lands where a float is read.

## Metadata vs other mechanisms

| Feature | Metadata | Component State | Signal Payload |
|---------|----------|-----------------|----------------|
| Purpose | Tags and measurements about an entity | Persistent component data | Actual data transfer |
| Scope | Signal / Component / Port / Group / Mesh | Single component | Single signal |
| Type | `string` → `string \| float64` | Any type | Any type |
| Persistence | Travels with the entity | Persists across cycles | Consumed in cycle |
| Best for | Routing, filtering, weights, scores, debugging | Counters, state machines | Business data |
