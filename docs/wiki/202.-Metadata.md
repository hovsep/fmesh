## Overview

Signals, signal groups, components, ports, port groups, collections, cycles, cycle groups and the mesh all carry a **metadata store**: `*meta.Meta`. It maps string keys to values. Use it to route, filter and debug without touching the payload. The idea comes from Kubernetes labels.

One store, one key space, simple value types:

- **string** — `"priority": "high"`, `"source": "sensor1"`
- **bool** — `"critical": true`
- **any Go integer or float** — `"retries": 3`, `"weight": 0.85`, `"size": uint64(1024)`
- **your own types built on these** — `"temp": Celsius(36.6)`, `"state": Status("ready")`

The type is chosen per entry. Writes infer it from the value. Reads name it at the call site. See the [meta package](https://pkg.go.dev/github.com/hovsep/fmesh/meta).

## Core API

```go
m := meta.New()

// Write (add or update). The type comes from the value.
m.Set("env", "prod")
m.Set("weight", 0.85)
m.Set("retries", 3)
m.Set("critical", true)
m.SetMany(map[string]string{"region": "us-west", "tier": "backend"})
m.SetMany(map[string]float64{"latency_ms": 42, "load": 0.7})

// Read: name the type you expect
env, err := m.Value[string]("env")    // error if absent or not a string
w, err := m.Value[float64]("weight")  // error if absent or not a float64
n, err := m.Value[int]("retries")     // error if absent or not an int

// Read: the type comes from the default or the comparison value
region := m.ValueOrDefault("region", "unknown")
weight := m.ValueOrDefault("weight", 0.0)
if m.ValueIs("env", "prod") { /* ... */ }
if m.ValueIs("retries", 0) { /* ... */ }

// Presence
m.Has("env")               // true
m.Has("env", "weight")     // all present (no keys: true)
m.HasAny("dev", "staging") // at least one present

// Shape
m.Keys()    // sorted
m.Len()
m.IsEmpty()
m.All()     // copy, map[string]any

// Remove
m.Remove("load", "tier") // missing keys are ignored
m.Clear()

// New stores (the receiver is not changed)
clone := m.Clone()
onlyStrings := m.Filter(func(key string, value any) bool {
    _, ok := value.(string)
    return ok
})
```

Write methods return the store, so they chain: `m.Set("a", "1").Set("b", 2.0)`.

### Rules the compiler enforces

**Only simple types.** `string`, `bool`, every Go integer and float type, and your own types built on them. Structs, slices and maps do not compile.

```go
type Celsius float64

m.Set("count", 3)                 // ok, stored as int
m.Set("ratio", float32(0.5))      // ok, stored as float32
m.Set("temp", Celsius(36.6))      // ok, stored as Celsius
m.Set("tags", []string{"a"})      // compile error: []string does not satisfy meta.Value
```

**Numbers are not converted.** An entry reads back only as the type it was written with. An untyped `3` is an `int`, and `3.0` is a `float64`:

```go
m.Set("count", 3)
m.Value[int]("count")             // 3
m.Value[int64]("count")           // error: meta "count" holds int, not int64
m.ValueOrDefault("count", 0)      // 3
m.ValueOrDefault("count", 0.0)    // 0.0 — the default, because the entry is an int
```

The same goes for your own types: a `Celsius` entry reads with `Value[Celsius]`, not `Value[float64]`. Pick one type per key and use it on both sides.

**A key holds one type at a time.** `Set("k", 1.0)` after `Set("k", "one")` replaces the entry. A read with the wrong type is an error from `Value`. For `ValueOrDefault` and `ValueIs` it is the same as a missing key:

```go
m.Set("port", "8080")
_, err := m.Value[float64]("port") // meta "port" holds string, not float64
m.ValueOrDefault("port", 0.0)      // 0.0
m.ValueIs("port", 8080.0)          // false
```

## Copy-on-write vs mutating

| Entity | Style | Add one | Add many | Remove | Replace all |
|--------|-------|---------|----------|--------|-------------|
| `signal.Signal` | Copy-on-write | `WithMeta(k, v)` | `WithMetaMany(map)` | `WithoutMeta(keys...)` | `WithoutMeta(s.Meta().Keys()...).WithMetaMany(map)` |
| `signal.Group` (its own store) | Copy-on-write | `WithMeta(k, v)` | — | — | — |
| Everything else | Mutating, through the store | `Meta().Set(k, v)` | `Meta().SetMany(map)` | `Meta().Remove(keys...)` | `Meta().Clear().SetMany(map)` |

- **Signals and signal groups** are immutable. `With*` returns a new value; assign it. Their `Meta()` returns a **copy**, so changing it does nothing.
- **Everything else** (components, ports, the mesh, cycles, collections) mutates in place. These types have no metadata methods of their own. `Meta()` returns the live store:

```go
c.Meta().Set("layer", "business-logic").Set("owner", "team-a").Set("weight", 0.5)
```

So `With*` has one meaning across the whole API: it returns something new.

## Signals

```go
sig := signal.New("temperature: 25°C").WithMetaMany(map[string]string{
    "source":   "sensor1",
    "type":     "temperature",
    "priority": "normal",
})

// Chain, and assign the result
sig = sig.WithMeta("processed", "true").WithMeta("confidence", 0.97)

// Query
if sig.Meta().ValueIs("priority", "high") { /* ... */ }
priority := sig.Meta().ValueOrDefault("priority", "normal")
confidence := sig.Meta().ValueOrDefault("confidence", 0.0)
```

Filter with the predicate helpers from the `signal` package:

```go
highPriority := port.Signals().Filter(signal.MetaEquals("priority", "high"))
confident := port.Signals().Filter(signal.MetaEquals("confidence", 1.0))
fromSensors := port.Signals().Filter(signal.MetaContains("source", "sensor"))
urgent := port.Signals().Filter(signal.HasAnyMeta("urgent", "critical", "emergency"))
traced := port.Signals().Filter(signal.HasMeta("trace-id", "span-id"))
```

All helpers: `Not`, `And`, `Or`, `HasMeta`, `HasAnyMeta`, `MetaEquals`, `MetaContains` (see [Signals](https://github.com/hovsep/fmesh/wiki/201.-Signals#predicate-helpers)).

Metadata travels with the signal through pipes. This makes it a good way to track data across the mesh.

## Components

```go
c, err := component.New("processor",
    component.WithMeta("layer", "business-logic"),
    component.WithMeta("weight", 0.5),
    component.WithInputs("in"),
    component.WithOutputs("out"),
    component.WithActivationFunc(myFunc),
)

// After creation: the live store
c.Meta().Set("version", "2.0").Set("owner", "team-a")
c.Meta().Clear().SetMany(map[string]string{"layer": "business-logic", "criticality": "high"})

// Find components by metadata
critical := fm.Components().Filter(func(c *component.Component) bool {
    return c.Meta().ValueIs("criticality", "high")
})
```

## Ports

```go
dataPort, err := port.NewInput("data",
    port.WithMeta("type", "primary"),
    port.WithMeta("required", "true"),
)

c.InputByName("config").Meta().
    Set("type", "configuration").
    Set("optional", "true")

required := c.Inputs().Filter(func(p *port.Port) bool {
    return p.Meta().ValueIs("required", "true")
})
```

## Groups and collections

Every group and collection has its **own** store, separate from its contents. `signal.Group` also has batch methods that touch every signal inside. They are copy-on-write:

```go
// On every signal in the group
tagged := port.Signals().WithMetaOnEach("batch", "2024-01-01")
tagged = tagged.WithoutMetaOnEach("draft")

// On the group's own store
tagged = tagged.WithMeta("source", "pipeline")
```

The mutating types (`port.Collection`, `component.Collection`, `port.Group`, `cycle.Group`) have no batch methods. Loop over `All()` and use each element's own store.

## Common use cases

### Priority-based routing

```go
router, err := component.New("router",
    component.WithInputs("in"),
    component.WithOutputs("high", "low", "normal"),
    component.WithActivationFunc(func(ctx context.Context, this *component.Component) error {
        for sig := range this.InputByName("in").Signals().All() {
            out := "normal"
            if p := sig.Meta().ValueOrDefault("priority", "normal"); p == "high" || p == "low" {
                out = p
            }
            if err := this.OutputByName(out).PutSignals(sig); err != nil {
                return err
            }
        }
        return nil
    }),
)
```

### Measurements next to tags

The payload is a type tag. The numbers live in metadata.

```go
sig := signal.New("air").
    WithMeta("category", "gas").
    WithMeta("temperature", 26.4).
    WithMeta("humidity", 0.55)

if sig.Meta().ValueIs("category", "gas") {
    t := sig.Meta().ValueOrDefault("temperature", 0.0)
}
```

### Source tracking

```go
sig := signal.New(data).WithMetaMany(map[string]string{
    "source":     "api-gateway",
    "request-id": "abc-123",
    "trace-id":   traceID,
})
```

## Best practices

- **Consistent key names**, for example `app.name`, `app.version`, `app.environment`.
- **Payload for data, metadata for context.** Keep the store small: every copy-on-write step clones it.
- **One type per key, across the mesh.** The store does not know that `"temperature"` is always a number. Your components must agree. Keep that agreement in one place, for example a `const` per key.

## Metadata vs other mechanisms

| | Metadata | Component state | Signal payload |
|--|----------|-----------------|----------------|
| Purpose | Tags and measurements about an entity | Data a component keeps | The data itself |
| Scope | Signal, group, component, port, cycle, mesh | One component | One signal |
| Value type | `string`, `bool` or a number | Any | Any |
| Lifetime | Travels with the entity | Kept across cycles | Consumed in a cycle |
| Best for | Routing, filtering, weights, debugging | Counters, state machines | Business data |
