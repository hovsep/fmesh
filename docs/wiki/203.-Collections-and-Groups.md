## Overview

F-Mesh has two ways to hold many entities:

- **Collection** — indexed by unique name. Used for components and ports.
- **Group** — an ordered list. Used for signals, pipes and cycles.

Both share one read surface: `Len`, `IsEmpty`, `All`, `First`, `Find`, `Any`, `Every`, `Count`, `Filter`. What you learn on one type works on the others.

One rule covers this whole page: **`signal.Group` is copy-on-write; everything else mutates in place.**

- `With*` / `Without*` on `signal.Group` return a new group.
- `Add` / `Remove` / `Meta().Set(...)` on the other types change the receiver.

---

## Iterating

Every collection and group has `All()`, which returns an `iter.Seq`. Range over it:

```go
for c := range fm.Components().All() { // name order
    fmt.Println(c.Name())
}

for s := range port.Signals().All() { // insertion order
    fmt.Println(s.Payload())
}
```

- `break`, `continue` and `return` work as in any loop. To stop on an error, return it.
- `All()` allocates nothing. For a slice, collect it: `slices.Collect(port.Signals().All())`.
- On a collection, the loop body may add or remove entities: the walk keeps the list it started with.

## Collections

| Type | Holds |
|------|-------|
| `component.Collection` | components, by name |
| `port.Collection` | ports, by name |

- **Named access** — `ByName` returns the entity, or `nil`.
- **Unique names** — adding a duplicate name is an error.
- **Name order** — every traversal (`All`, `Filter`, `Find`, …) goes in name order. It is the same on every run.

### Read

```go
c := fm.Components().ByName("processor")        // nil if not found
p := c.Inputs().ByName("in1")                   // nil if not found
ports := c.Inputs().ByNames("in1", "in2", "in3") // unknown names are skipped

fm.Components().IsEmpty()
fm.Components().Len()
```

`First()` returns the first entity in name order, or nil.

### Query

```go
isActive := func(c *component.Component) bool {
    return c.Meta().ValueIs("status", "active")
}

active := fm.Components().Filter(isActive)   // new collection
first := fm.Components().Find(isActive)      // first match in name order, or nil
anyActive := fm.Components().Any(isActive)
allActive := fm.Components().Every(isActive) // true on an empty collection
count := fm.Components().Count(isActive)
```

### Add and remove

Collections mutate in place:

```go
comps := component.NewCollection()
err := comps.Add(c1, c2, c3)      // error on a duplicate name
comps.Remove("old", "deprecated") // unknown names are ignored
```

For a subset that leaves the original alone, use `Filter`.

### port.Collection extras

```go
this.Inputs().AllHaveSignals()
this.Inputs().AnyHasSignals()

all := c.Inputs().Signals() // all signals of all ports, in port-name order
```

Create indexed ports with `component.WithIndexedInputs` / `WithIndexedOutputs` — see [Component](https://github.com/hovsep/fmesh/wiki/301.-Component#indexed-ports).

## Groups

| Type | Mutability | Holds |
|------|------------|-------|
| `signal.Group` | **copy-on-write** | signals: a port's buffer, a batch in flight |
| `port.Group` | read-only to users | ports: a port's outbound pipes (`p.Pipes()`) |
| `cycle.Group` | mutates in place | cycle history (`RuntimeInfo.Cycles`) |

- **Ordered** — insertion order is kept (first in, first out).
- **Duplicates allowed.**

`signal.Group` is copy-on-write because signals are shared by pointer across pipes. A change must not leak into another component's view.

### Read

```go
first := port.Signals().First() // nil if empty
last := port.Signals().Last()   // nil if empty
found := port.Signals().Find(signal.MetaEquals("priority", "high")) // nil if none

port.Signals().IsEmpty()
port.Signals().Len()

cyc := ri.Cycles.ByNumber(3) // nil if not kept (see the history limit)
```

### Build

```go
group := signal.NewGroup(1, "hello", 3.14, true)

// Copy-on-write: assign the result
group = group.With(signal.New(42)) // nil signals are skipped
group = group.WithPayloads(5, 6, 7)
group = group.Join(otherGroup)
```

### Query

```go
high := port.Signals().Filter(signal.MetaEquals("priority", "high")) // new group
hasUrgent := port.Signals().Any(signal.HasMeta("urgent"))
allDone := port.Signals().Every(signal.HasMeta("processed"))
n := port.Signals().Count(signal.HasMeta("retry"))

port.Signals().ContainsPayload(42) // any comparable value
port.Signals().Any(func(s *signal.Signal) bool { /* slices, maps */ return false })
```

### Transform

All return a new group. Each signal keeps its metadata (with `Map`, unless your mapper replaces it).
The group's own metadata is not carried over: the result starts with an empty store.

```go
isInt := func(s *signal.Signal) bool { _, err := s.As[int](); return err == nil }
double := func(p any) any { return p.(int) * 2 }

doubled := port.Signals().MapPayloadsIf(isInt, double)         // only ints; others kept as-is
doubledAll := port.Signals().Filter(isInt).MapPayloads(double) // every payload

// Whole-signal mappers; nil results are dropped
tagged := port.Signals().Map(func(s *signal.Signal) *signal.Signal {
    return s.WithMeta("seen", "true")
})
taggedInts := port.Signals().MapIf(isInt, func(s *signal.Signal) *signal.Signal {
    return s.WithMeta("kind", "int")
})
```

`Map` and friends exist on `signal.Group` only. The other containers hold live entities: change them in a loop over `All()`, and use `Filter` for a subset.

### Reduce

```go
// Fold payloads into a typed accumulator
sum := port.Signals().ReducePayloads(0, func(acc int, p any) int {
    n, _ := p.(int)
    return acc + n
})
```

### Payloads

```go
for p := range port.Signals().Payloads() { // iterator, like All()
    fmt.Println(p)
}
payloads := slices.Collect(port.Signals().Payloads())

payload, err := port.Signals().FirstPayload() // ErrNoSignalsInGroup if empty
payload = port.Signals().FirstPayloadOrNil()

// Typed: error or default on an empty group or a wrong type
n, err := port.Signals().FirstAs[int]()
n = port.Signals().FirstPayloadOrDefault(0) // type comes from the default
```

See [Reading typed payloads](https://github.com/hovsep/fmesh/wiki/201.-Signals#reading-typed-payloads) for when to use which.

## Metadata on groups and collections

| Level | What it touches | Methods | Where |
|-------|-----------------|---------|-------|
| Own store | The group or collection itself | `WithMeta` on `signal.Group`; `Meta().Set(...)` elsewhere | everywhere |
| Contents | Each signal inside | `WithMetaOnEach`, `WithoutMetaOnEach` | `signal.Group` only |

`signal.Group.Meta()` returns a **copy**. Changing it does nothing:

```go
g.Meta().Set("k", "v")   // changes a copy; g is unchanged
g = g.WithMeta("k", "v") // correct
```

On the mutating types, `Meta()` is the live store. They have no batch methods for contents: loop over `All()` and use each element's own store. See [Metadata](https://github.com/hovsep/fmesh/wiki/202.-Metadata).

`Filter` results start with empty metadata on every type.

## Determinism

[Run determinism](https://github.com/hovsep/fmesh/wiki/401.-Scheduling-rules) comes from here:

1. **Within one port** — signals keep insertion order (FIFO).
2. **Across ports and components** — every collection traversal goes in name order.

With deterministic activation functions, the same input gives the same output on every run.

---

## Errors and nil

- Methods that can fail return `error` last (`Add`, `FirstAs`, …).
- Lookups return `nil` when nothing is found (`ByName`, `ByNumber`, `Find`, `First`, `Last`).

```go
c := fm.ComponentByName("missing")
if c == nil {
    return errors.New("component not found")
}
```

> [!WARNING]
> `ByNames` silently skips names that match nothing. `AllHaveSignals()` on an empty collection is `true`.
> So a typo in a port name reads as "ready". `component.RequireInputs` checks every name and reports the one it cannot find.

## Common patterns

### Wait until all inputs have signals

```go
component.WithActivationFunc(func(ctx context.Context, this *component.Component) error {
    if !this.Inputs().ByNames("in1", "in2").AllHaveSignals() {
        return component.ErrWaitKeepingInputs
    }
    // process inputs
    return nil
})
```

### Filter, then act

```go
critical := fm.Components().Filter(func(c *component.Component) bool {
    return c.Meta().ValueIs("criticality", "high")
})
for c := range critical.All() {
    log.Printf("critical component: %s", c.Name())
}
```

### Stop on the first error

```go
for s := range this.InputByName("in").Signals().All() {
    if err := this.OutputByName("out").PutSignals(s); err != nil {
        return err
    }
}
```

## Same methods everywhere

| | Collection | Group |
|--|------------|-------|
| Iterate | `All()` (name order) | `All()` (insertion order) |
| Access | `ByName`, `ByNames`, `First` | `First`, `Last` |
| Query | `Filter`, `Find`, `Any`, `Every`, `Count` | `Filter`, `Find`, `Any`, `Every`, `Count` |
| Names unique | yes | no |
| Use for | entities with names | anonymous or ordered entities |

```go
fm.Components().Filter(pred)
c.Inputs().Filter(pred)
port.Signals().Filter(pred)
```
