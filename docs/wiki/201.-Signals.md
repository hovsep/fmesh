## Overview

A **signal** is the unit of data that moves between components. It has two parts:

1. **Payload** — the data. Any Go value, including `nil`.
2. **Metadata** — optional key-value entries (string or `float64` values) for routing, filtering and debugging.

Every signal has a payload. There is no "empty" signal: a `nil` payload is still a payload.

```go
sig := signal.New("example payload")
```

Full API: [signal package](https://pkg.go.dev/github.com/hovsep/fmesh/signal).

## Immutability (copy-on-write)

Signals are **immutable**. `WithMeta`, `WithMetaMany`, `WithoutMeta` and `MapPayload` return a **new** signal. The original never changes.

This matters on fan-out: several ports can hold the same signal pointer. Immutability stops one component from changing what another one sees.

```go
original := signal.New("hello")
tagged := original.WithMeta("source", "sensor1")

original.Meta().Has("source") // false
tagged.Meta().Has("source")   // true
```

Always assign the result:

```go
sig = sig.WithMeta("processed", "true")
```

`sig.Meta()` returns a **copy** of the store. Changing that copy does not change the signal.

The payload itself is shallow. If it is a pointer, slice or map, do not mutate it: other components may read it at the same time.

## Reading typed payloads

The payload is `any`, because one pipe can carry mixed types. To read it as a concrete type, use one of two generic methods:

```go
// Returns an error on a wrong type. Never panics.
temperature, err := sig.As[float64]()
if err != nil {
    return err
}

// Returns the default on a wrong or missing type.
retries := sig.PayloadOrDefault(0)
```

Both are safe on a nil `*Signal`. `Group.First()` returns nil for an empty group, so reading from a port is one chain:

```go
n, err := this.InputByName("in").Signals().FirstAs[int]()      // ErrNoSignalsInGroup when empty
n := this.InputByName("in").Signals().FirstPayloadOrDefault(0) // default when empty or wrong type
```

`As` returns an error instead of panicking on purpose. A component cannot know that an upstream component changed its payload type. A panic would stop the whole mesh.

> [!WARNING]
> **Prefer `As`.** `PayloadOrDefault` cannot tell "wrong type" from "missing", and it reports neither.
> If a producer changes from `int` to `int64`, everything downstream quietly gets `0`.
> Use `PayloadOrDefault` only when the default is the correct answer for a wrong type.

```go
// Upstream changed int -> int64:
price := sig.PayloadOrDefault(0) // 0, no error
price, err := sig.As[int]()      // error: "signal payload is int64, not int"
```

`PayloadOrDefault` infers the type from the default, so there are no per-type helpers like `AsInt`:

```go
sig.PayloadOrDefault(0)     // int
sig.PayloadOrDefault("")    // string
sig.PayloadOrDefault(false) // bool
```

> [!IMPORTANT]
> An untyped `0` is an `int`. So `sig.PayloadOrDefault(0)` on a **float64** payload returns `0`, not the payload.
> Pass `0.0`, or use `sig.Float64OrDefault(0)` — the one per-type shorthand, kept for this reason.

Two more readers:

- `sig.AsGroup()` — the payload as a `*signal.Group`, for a signal that carries other signals.
- `sig.AsNumber()` — returns `(float64, bool)`. See below.

### AsNumber

`AsNumber` is the loose reader. It accepts `float64`, `float32`, `int`, `int64` and `uint64`. A `bool` becomes `1` or `0`. Anything else returns `false`.

```go
if value, ok := sig.AsNumber(); ok {
    // the signal carries a measurement
}
```

Use it when code must decide if a signal is a number **at all** — for example a logger or a visualizer. It does not need to know which component produced the signal. A payload may be a type tag like `"air"`, with the real values in [metadata](#metadata).

## Signal Groups

A **signal group** is an ordered list of signals. Each signal can carry a different payload type. A port's signals are a group.

```go
group := signal.NewGroup(1, nil, 3, []int{4, 5, 6}, map[byte]byte{7: 8})

port.Signals().Filter(signal.HasMeta("priority"))
```

Groups are copy-on-write too. For the full group API (filter, map, reduce, iterate), see [Collections and Groups](https://github.com/hovsep/fmesh/wiki/203.-Collections-and-Groups).

## Metadata

**Metadata** describes a signal without changing its payload. Each value is a `string` or a `float64`. Use `With*` methods and assign the result:

```go
sig := signal.New("measurement").WithMetaMany(map[string]string{
    "priority": "high",
    "source":   "sensor1",
})

// Strings and numbers share one store
sig = sig.WithMeta("weight", 0.85)

// Read: the type comes from the comparison value or the default
if sig.Meta().ValueIs("priority", "high") {
    // handle high priority
}
weight := sig.Meta().ValueOrDefault("weight", 0.0)

// Remove
sig = sig.WithoutMeta("source")
```

| Method | Description |
|--------|-------------|
| `WithMeta(key, value)` | Add or update one entry (string or float64) |
| `WithMetaMany(map)` | Add or update many |
| `WithoutMeta(keys...)` | Remove entries |

Metadata travels with the signal through pipes. For the full store API, see [Metadata](https://github.com/hovsep/fmesh/wiki/202.-Metadata).

## Predicate helpers

The `signal` package has composable predicates for `Filter`, `Find`, `Any`, `Every` and `Count`:

```go
port.Signals().Filter(signal.And(
    signal.HasMeta("priority"),
    signal.MetaEquals("priority", "high"),
))

port.Signals().Filter(signal.Or(
    signal.MetaEquals("source", "sensor1"),
    signal.MetaEquals("source", "sensor2"),
))
```

| Helper | Matches when |
|--------|--------------|
| `HasMeta(keys...)` | all keys are present |
| `HasAnyMeta(keys...)` | at least one key is present |
| `MetaEquals(key, value)` | the key holds exactly this value (string or float64) |
| `MetaContains(key, substr)` | the key holds a string that contains `substr` |
| `Not(p)`, `And(p1, p2)`, `Or(p1, p2)` | combine predicates |

## Function types

| Type | Signature | Used by |
|------|-----------|---------|
| `Predicate` | `func(*Signal) bool` | `Filter`, `Find`, `Any`, `Every`, `Count`, `MapIf` |
| `Mapper` | `func(*Signal) *Signal` | `Map`, `MapIf` |
| `PayloadMapper` | `func(any) any` | `MapPayload`, `MapPayloads` |
| `Reducer` | `func(acc, s *Signal) *Signal` | `Reduce` |

## Errors

| Error | When |
|-------|------|
| `ErrNoSignalsInGroup` | `FirstPayload()` or `FirstAs[T]()` on an empty group |

`Payload()` never fails. A nil payload is valid.
